# Cheat sheets — minimalist Windows dev stack

One file per tool. Each follows the same shape:

- **Purpose** — what it replaces or makes possible
- **3 main use cases** — the daily-driver patterns
- **Trickery** — non-obvious power moves worth knowing

Read in this order if you're new to the stack:

1. [komorebi](komorebi.md) — tiling window manager
2. [whkd](whkd.md) — keybinding daemon (drives komorebi)
3. [yasb](yasb.md) — status bar
4. [WezTerm](wezterm.md) — terminal + multiplexer
5. [Files](files.md) — GUI file manager
6. [yazi](yazi.md) — TUI file manager
7. [PowerToys](powertoys.md) — selective Windows utilities
8. [Scoop](scoop.md) — CLI package manager
9. [ripgrep](ripgrep.md) — recursive grep
10. [fd](fd.md) — friendly find
11. [fzf](fzf.md) — fuzzy finder
12. [bat](bat.md) — cat with syntax highlighting
13. [eza](eza.md) — modern ls
14. [jq](jq.md) — JSON processor
15. [gh](gh.md) — GitHub CLI
16. [vim](vim.md) — modal text editor
17. [zoxide](zoxide.md) — smarter cd
18. [starship](starship.md) — shell prompt
19. [Sysinternals](sysinternals.md) — Windows process tools
